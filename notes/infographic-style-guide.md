# 教材信息图视觉规范

版本：0.1，最后更新：2026-08-09。

## 设计原则

信息图首先帮助读者定位层级、边界、顺序和风险，其次才是装饰。每张图只设置一个主阅读方向和一个视觉中心；背景插画不得干扰箭头、标签和边界。

## 颜色语义

| 颜色 | 建议色值 | 固定语义 |
|---|---|---|
| 深蓝 | `#24476B` | 模型、Agent Runtime、核心控制 |
| 青绿 | `#178F82` | 数据、RAG、Memory、检索 |
| 暖橙 | `#D9782D` | Tool、MCP、外部系统、副作用 |
| 紫色 | `#7656A5` | Workflow、Planning、Multi-Agent |
| 红色 | `#B94A48` | 风险、拒绝、审批、攻击路径 |
| 中灰 | `#637381` | 基础设施、辅助信息、非主路径 |
| 暖白 | `#F7F5F0` | 纸张与画布背景 |

颜色只作为辅助编码。不同语义还必须通过形状、分组标题、线型、图标或编号区分，确保灰度打印可读。

## 图形语言

- 核心组件使用圆角矩形，数据存储使用稳定的存储图形，外部主体使用独立轮廓。
- 实线表示主控制或数据流；虚线表示配置、反馈、观测或非同步关系。
- 高风险路径必须有明确门禁或边界，不只改变颜色。
- 复杂图使用 ①②③ 编号建立阅读顺序，图后文字按相同编号解释。
- 单张图建议控制在 7—12 个一级对象；更多对象应分组或拆为局部图。

## 生成式视觉底稿约束

- 底稿不得包含有意义的文字、数字、Logo、水印、代码或 UI 截图。
- 底稿不得决定技术关系；箭头和边界由 SVG 语义层重建。
- 风格为现代中文技术教材的扁平矢量编辑插画，避免科幻霓虹、拟真机器人和营销海报风格。
- 画面保留充足负空间，方便后续覆盖准确中文标签。
- 避免细碎纹理、低对比度渐变和仅在大屏幕上可见的微小元素。

## 字体与尺寸

- 中文：Noto Sans SC；英文与数字沿用 Noto Sans SC 或 Source Code Pro。
- 标题、分区标题和节点标签至少形成三级层次。
- A4 成品在 100% 缩放时，最小正文标签不得低于约 9pt 的视觉尺寸。
- 横向图优先使用接近 3:2 的画布；特别复杂的全景图允许 16:9，但必须验证 PDF 缩放后的文字大小。

## 输出要求

每张最终图至少包含：

```text
source/<semantic-id>-base.png
svg/<semantic-id>.svg
png/<semantic-id>-2x.png
```

Markdown 中必须提供图题、替代文本和图后解释。SVG 是网页与 PDF 的首选，PNG 是 EPUB 和不支持 SVG 环境的回退资源。
