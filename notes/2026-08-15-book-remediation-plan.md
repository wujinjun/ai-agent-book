# 《AI Agent 从零到实战（2026版）》内容、排版与图文整改计划

制定日期：2026-08-15
依据报告：`notes/2026-08-15-book-content-layout-visual-review.md`
计划范围：教材正文、项目教学内容、图稿、HTML 阅读版、PDF 和 EPUB
明确排除：配套软件功能开发、示例程序重构、项目运行验证、测试程序扩建、CI 和外部生产环境验证

## 1. 整改目标

本计划把现有“内容丰富的课程讲义”提升为结构连续、图文互补、三种格式均可舒适阅读的正式教材候选。

完成后应达到：

| 目标 | 验收结果 |
|---|---|
| 内容结构 | 38章核心正文全部位于总结之前，章节标题符合主题逻辑 |
| 教学连续性 | 七篇形成明确能力主线，跨章术语和案例自然衔接 |
| 项目篇 | 十项目具有独立教材章节，而不只是运行 README |
| 工程图 | 无不可读的超宽图，复杂关系完成拆分或改版 |
| 信息图 | 视觉语言统一，小屏和纸张均可读，一图一问 |
| HTML | 桌面与 390 px 移动端可读，读者导航不暴露维护页面 |
| PDF | 封面、目录、篇章页、代码、表格、图片和分页达到图书版式 |
| EPUB | 图稿针对电子阅读优化，文件体积显著下降 |
| 学术与编辑 | 重要论断就近引用，术语统一，练习与答案分离 |
