# HTML 响应式版式验收

验收日期：2026-08-08

构建入口：`.venv/bin/python scripts/build_html.py`

验收对象：`output/html/`

## 结论

MkDocs Material 严格构建通过。使用应用内浏览器分别在 1440×900、768×1024 和 390×844 视口抽检首页、企业培训入口、第 8 章、第 28 章与参考资料页；正文、图号、SVG、PNG Trace 截图、代码块和表格均可阅读，最终页面级横向溢出为 0。

## 抽检矩阵

| 视口 | 代表设备 | 页面 | 结果 |
|---|---|---|---|
| 1440×900 | 桌面浏览器 | 首页、第 8/28 章、参考资料 | 通过；顶部导航使用自身横向滚动区域，不扩张正文 |
| 768×1024 | 平板竖屏 | 企业培训、第 8/28 章 | 通过；文档根节点 `scrollWidth == 768` |
| 390×844 | 手机竖屏 | 首页、企业培训、第 8/28 章、参考资料 | 通过；文档根节点 `scrollWidth == 390` |

第 28 章移动端实测读取到 `图 28-1` 至 `图 28-4`，Trace PNG 正常加载。浏览器控制台未发现页面脚本错误。

## 本轮修复

- Material 表格滚动容器的负边距在 768px 视口造成 15px 页面溢出；现将滚动容器限制在正文宽度内。
- 图号统一为章节、项目、导读和培训作用域编号，并在 HTML 中使用高对比度字重呈现。
- 新增版权页与版本页后重新构建导航并复测三种视口。

## 边界

390px 与 768px 是浏览器设备视口仿真，不冒充实体手机或平板。实体 iOS/Android 的字体替换、系统缩放与辅助技术检查继续纳入 P9 外部设备抽检。
