    学员实验手册

    实验规则

    每个实验必须提交可运行结果和解释材料。截图只能辅助说明，不能替代源码、测试或结构化输出。默认使用 Mock、Fixture 和本地存储；在线模式仅在讲师明确允许、预算和数据范围已经确定时启用。

    这套顺序防止学员只展示最终结果而忽略假设、失败和设计取舍。

    统一提交结构

    submission/<student-id>/<lab-id>/
├── README.md
├── evidence/
│   ├── test-result.txt
│   ├── sample-output.json
│   └── trace.json
├── src/
├── tests/
└── decision.md

    decision.md 至少回答：选择了什么、为什么、替代方案是什么、失败时如何恢复、哪些结论尚未验证。

    核心实验清单

    ID 关联章节/代码 建议时间 编码任务 必交证据 通过标准
    L01 第2、31章；examples/token_counter/ 90 分钟 建立上下文与成本预算器 三组输入统计、预算拒绝测试 超预算请求不会静默继续
    L02 第3—4章；examples/attention_demo/、sampling_lab/ 120 分钟 对照 Attention 与采样参数 参数表、可重复性说明 能区分注意力和解码采样
    L03 第5章；examples/local_semantic_search/ 120 分钟 构建本地语义检索 查询集、Recall@k、失败案例 无关查询能拒答或低分
    L04 第6—7章；prompt_registry/、structured_extractor/ 120 分钟 版本化 Prompt 与结构化抽取 Schema、非法输出测试 校验失败不进入业务写入
    L05 第8—10章；minimal_agent/、项目2 180 分钟 工具调用 Agent 超时、权限、幂等、终止测试 循环有上限，副作用可审计
    L06 第11—12章；项目3 150 分钟 MCP Tool/Resource/Prompt 能力发现记录、错误响应 客户端不把 MCP 当远程信任根
    L07 第13—16章；项目4 240 分钟 版本化 RAG 黄金集、引用、索引切换记录 发布门禁失败时旧索引仍有效
    L08 第23—27章；项目1或10 240 分钟 Agent API 与持久任务 OpenAPI、重启恢复、SSE 游标 重启不丢失已确认状态
    L09 第28—29章；项目4/8/10 180 分钟 Trace 与回归评估 黄金集、指标、失败样本 能定位一次质量下降的环节
    L10 第30章；项目2/5/6 150 分钟 Prompt Injection 威胁实验 威胁模型、攻击 Fixture、审计 间接注入不能提升工具权限
    L11 第20、32、36章；项目8/9 240 分钟 单 Agent 与多 Agent 对照 成功率、成本、延迟、终止统计 用数据证明是否需要多 Agent
    L12 第37—38章；任一完整项目 8—16 小时 综合产品化冲刺 README、ADR、测试、演示说明 陌生工程师可复现并解释取舍

    实验执行模板

    每个实验按以下步骤执行：

    1. 阅读任务关联章节与示例 README，写出成功条件和两个预期失败。
    2. 运行未修改的离线基线，并保存测试命令和环境版本。
    3. 只修改任务要求范围，避免把外部服务或新框架当作捷径。
    4. 增加至少一个成功测试和一个失败/边界测试。
    5. 保存最小必要 Trace，删除密钥、个人数据和无关 Prompt 内容。
    6. 使用评分标准自评，再进行同伴评审。

    无付费账号运行

    执行：

    python3.12 scripts/setup_training_env.py --target .training-workspace
source .venv/bin/activate
python -m pytest -q

    初始化脚本复制稳定 Fixture 并生成训练清单，不创建真实密钥。在线扩展应在离线测试全部通过后单独执行，并记录 Provider、模型、日期、预算和数据范围。

    实验失败时如何求助

    求助信息至少包含命令、Python 版本、最小错误日志、预期结果、已经尝试的诊断和是否涉及外部服务。不得发送 .env、Token、完整生产日志或客户文档。先查看常见学员错误，仍无法解决时再提交最小复现。
