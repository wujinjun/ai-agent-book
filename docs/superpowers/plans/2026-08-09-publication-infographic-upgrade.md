# 出版级信息图升级实施计划

计划日期：2026-08-09。

## 目标

在保留 Mermaid 精确性、可维护性和可追踪性的前提下，将全书最适合视觉叙事的概念体系、复杂架构、跨层数据流和安全边界升级为出版级信息图。最终图稿必须同时适配 MkDocs HTML、A4 PDF 和 EPUB3，不以视觉装饰替代技术准确性。

## 基本决策

全书采用三级视觉体系：

1. A 级核心信息图：预计 12 张，使用生成式视觉底稿与可编辑 SVG 语义图层。
2. B 级增强信息图：预计约 20 张，根据内容使用 SVG、增强 Mermaid 或混合图。
3. C 级精确工程图：其余 Mermaid 保持原有语义源码，用于状态、时序、重试、审批和算法流程。

生成式模型只承担构图、材质、视觉隐喻和非语义装饰。所有关键中文、箭头、编号、图例和边界必须由可编辑 SVG 或 HTML 图层承载；不得把模型生成的文字当作最终教材内容。

## 阶段四：出版管线集成

1. 为信息图建立确定性 manifest 和资源校验。
2. HTML 优先加载 SVG，并提供 PNG 回退和灯箱查看。
3. PDF 使用矢量图或高分辨率回退，控制分页和最大高度。
4. EPUB manifest 同时包含 SVG 与 PNG，验证 spine、图片引用和阅读器降级。
5. 保留原 Mermaid 源码；信息图与精确工程图承担不同阅读层级，避免内容重复。

## 验收标准

- 中文术语、组件关系和方向与正文一致。
- 不新增无来源的技术结论，不生成虚构 UI、代码或接口。
- 最终语义文字可编辑，并保持矢量清晰。
- HTML 桌面端与移动端可读；图片可放大查看。
- PDF A4 页面中关键标签清晰，图形不越界、不被分页截断。
- EPUB 不依赖 JavaScript，SVG 或 PNG 回退正常显示。
- 每张图有图号、图题、替代文本和图后解释。
- 灰度打印不依赖颜色表达唯一语义。
- 生成底稿、提示词、模型/工具信息和校验值可追溯。
- 三张样板通过后才批量生产其余图稿。
