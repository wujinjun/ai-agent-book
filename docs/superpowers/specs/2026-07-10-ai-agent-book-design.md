# 《AI Agent 从零到实战》教材工程设计

## 目标与边界

本工程面向具备软件工程经验、但尚未系统掌握 LLM 与 Agent 的中文读者。教材采用“原理—最小实现—工程实现—验证—边界”的教学链路，并将稳定理论与版本敏感 API 分开维护。

本轮优先交付可持续扩写的仓库骨架、第一篇正文、出版级第一节、可离线运行的核心示例、测试与状态报告。第 2—7 篇建立有内容摘要的章节入口，但只有达到统一章节模板要求的章节才能标记为完成。

## 信息架构

- `docs/` 保存教材正文，按七篇组织；每章独立文件。
- `examples/` 保存可独立运行的小型概念示例。
- `projects/` 保存十个端到端项目；未实现项目只在路线图中登记，不制造空工程。
- `src/ai_agent_book/` 保存可复用、可测试的教学代码。
- `tests/` 保存离线单元测试。
- `notes/version-check.md` 记录依赖版本、核对日期和待确认 API。
- `PROJECT_STATUS.md` 是唯一完成度事实源。

## 内容质量规则

章节必须定义概念、说明动机与机制、给出适用边界和工程陷阱。版本敏感内容必须注明核对日期；未经官方资料或本地依赖确认的接口只写概念和待核查项。第一节完整覆盖用户指定的 17 个主题且不少于 5000 个汉字。

## 代码与验证

首个代码纵切面是一个不依赖付费 API 的工具调用运行时：Pydantic 校验工具参数，异步执行工具，显式限制循环次数，并提供测试。文档通过 MkDocs 构建；Python 通过 pytest、Ruff 和 mypy 验证。PDF/EPUB 使用 MkDocs 与 Pandoc 脚本生成，缺少系统依赖时给出明确安装说明。

## 风险控制

不提交密钥，不默认执行高风险工具，不把模型输出当作已验证事实。对 OpenAI Agents SDK、PydanticAI、LangGraph、MCP 等快速变化组件，后续逐章核对官方文档并固定版本。
