# 术语表

| 术语 | 定义 |
|---|---|
| Agent | 由模型、状态、工具与控制循环组成，能够围绕目标选择并执行动作的软件系统。 |
| Context | 单次模型调用可见的消息、指令、工具结果与检索材料。 |
| Embedding | 将对象映射为数值向量、以便计算相关性的一种表示。 |
| Grounding | 用可追溯的外部数据约束生成，使回答能够关联证据。 |
| Hallucination | 输出在语言上合理但缺少事实依据、与上下文冲突或无法验证的内容。 |
| MCP | Model Context Protocol，用统一协议暴露工具、资源和提示等上下文能力。 |
| RAG | 生成前检索相关外部材料并注入上下文的系统模式。 |
| Token | Tokenizer 处理文本时使用的离散单元，不等同于汉字或单词。 |
| Tool Calling | 模型产生结构化工具意图，由宿主程序校验并执行，再把结果返回模型。 |
| Workflow | 由显式节点、状态与转移规则约束的执行过程。 |
