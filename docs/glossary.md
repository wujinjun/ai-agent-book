# 术语表

| 术语 | 类别 | 定义 |
|---|---|---|
| Agent（AI Agent） | 核心概念 | 由模型、状态、工具与控制循环组成，能够围绕目标选择并执行动作的软件系统。 |
| Agent Runtime（运行时） | 核心概念 | 负责保存状态、执行循环、调度工具、处理终止与恢复的宿主软件层。 |
| Attention（注意力） | 模型基础 | 根据查询与键的相关性对值进行加权组合的序列信息聚合机制。 |
| AutoGen | 框架 | 面向多 Agent 会话和协作编排的开源框架；具体接口应按安装版本核对。 |
| Checkpoint（检查点） | 工作流 | 对工作流状态进行持久化的快照，用于恢复、中断、回放和人工介入。 |
| Context（上下文） | 模型基础 | 单次模型调用可见的消息、指令、工具结果与检索材料。 |
| Context Engineering（上下文工程） | 工程 | 围绕任务选择、组织、压缩并验证模型可见信息的系统工程方法。 |
| CrewAI | 框架 | 以角色、任务和团队为主要抽象的多 Agent 编排框架。 |
| Embedding（嵌入向量） | 检索 | 将对象映射为数值向量，以便计算相似性或供下游模型使用的表示。 |
| Evaluation（评估） | 工程 | 使用数据集、指标、人工判断或模型裁判度量 Agent 行为质量与回归风险的过程。 |
| Grounding（依据约束） | 检索 | 用可追溯的外部数据约束生成，使回答能够关联证据。 |
| Guardrail（护栏） | 安全 | 在输入、动作和输出边界实施校验、权限、审批与内容策略的控制机制。 |
| Hallucination（幻觉） | 模型基础 | 输出在语言上合理但缺少事实依据、与上下文冲突或无法验证的内容。 |
| Handoff（移交） | 工作流 | 将任务、状态或控制权从一个 Agent 明确转交给另一个 Agent 的协作模式。 |
| Human in the Loop（HITL / 人工介入） | 工作流 | 在高风险或不确定步骤暂停自动执行，由人类检查、修改或批准后继续。 |
| Hybrid Search（混合检索） | 检索 | 联合稀疏检索、稠密向量检索或其他信号并融合排序的检索方法。 |
| LangChain | 框架 | 提供模型、工具、检索器和链式组合抽象的应用开发框架。 |
| LangGraph | 框架 | 以状态图、节点、边和检查点为核心的长任务与 Agent 工作流框架。 |
| LlamaIndex | 框架 | 以文档、节点、索引、检索器和查询引擎为核心的数据与 RAG 框架。 |
| MCP（Model Context Protocol） | 协议 | 用统一协议向模型应用暴露工具、资源和提示等上下文能力的开放协议。 |
| Memory（记忆） | 核心概念 | Agent 跨步骤或跨会话写入、保留、检索和遗忘信息的机制与数据层。 |
| Multi-Agent（多 Agent） | 核心概念 | 多个具有不同职责或能力的 Agent 通过消息、共享状态或监督者协作的系统结构。 |
| Observability（可观测性） | 工程 | 通过日志、指标、Trace、Token、成本和工具调用记录解释系统行为的能力。 |
| OpenAI Agents SDK | 框架 | OpenAI 提供的 Agent、工具、移交、护栏和追踪开发 SDK；接口须按当前官方版本核对。 |
| Prompt Injection（提示注入） | 安全 | 攻击者通过输入或间接内容诱使模型偏离可信指令、泄露数据或滥用工具的攻击方式。 |
| PydanticAI | 框架 | 强调 Python 类型、依赖注入、结构化结果与验证重试的 Agent 应用框架。 |
| RAG（Retrieval-Augmented Generation / 检索增强生成） | 检索 | 生成前检索相关外部材料并注入上下文的系统模式。 |
| Reranker（重排器） | 检索 | 对初次检索候选进行更精细相关性评分并重新排序的模型或规则组件。 |
| Semantic Kernel | 框架 | 微软提供的模型、插件、记忆和流程编排 SDK，支持多种语言与企业集成。 |
| Structured Output（结构化输出） | 工程 | 让模型结果满足 JSON Schema 或类型模型，并经解析与验证后进入软件边界的机制。 |
| Token（词元） | 模型基础 | Tokenizer 处理文本时使用的离散单元，不等同于汉字或单词。 |
| Tool Calling（Function Calling / 工具调用） | 核心概念 | 模型产生结构化工具意图，由宿主程序校验并执行，再把结果返回模型的交互模式。 |
| Transformer | 模型基础 | 以注意力、前馈网络、残差连接和位置表示为核心的神经网络架构族。 |
| Vector Database（向量数据库） | 检索 | 为高维向量相似性检索、元数据过滤和索引维护优化的数据系统。 |
| Workflow（工作流） | 工作流 | 由显式节点、状态与转移规则约束的执行过程。 |
