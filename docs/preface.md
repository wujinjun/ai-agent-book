# 前言

Agent 技术最容易出现两种偏差。一种只谈模型能力，把接口演示当成完整系统；另一种只谈框架节点和装饰器，却不解释框架在替开发者维护什么状态、承担什么失败语义。本书试图在两者之间建立可验证的工程路径。

教材不会用“预测下一个 Token”否定模型表现出的复杂能力，也不会因为模型能完成复杂任务就赋予它未经证实的人类式理解。我们关注可观察行为、训练目标、系统边界和工程证据。遇到学术争议时，会区分事实、解释框架与工程决策。

由于 Agent 生态变化迅速，稳定原理与版本敏感教程被分开维护。读者应把官方文档、当前依赖和测试结果视为 API 事实来源，把本书视为建立心智模型和工程方法的主线。
