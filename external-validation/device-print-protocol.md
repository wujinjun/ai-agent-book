# 实体设备与印刷样张协议

本协议验证自动 EPUB/PDF 审计无法证明的真实渲染问题。所有设备使用同一候选 commit 的 EPUB/PDF，并记录系统和阅读器版本；模拟器、浏览器响应式视口和桌面转换引擎不能替代此门禁。

## 实体 EPUB 设备

至少覆盖 iPhone、iPad 和 Android 手机；Android 平板可作为额外样本。每台设备从冷启动导入 EPUB，检查：

1. 目录能进入第一篇、第 8、18、28、38 章和最终验收页；返回目录后状态正常。
2. 中文字体、加粗、行内代码和代码块无方框、重叠或横向截断。
3. 抽查宽流程图、状态图、时序图和项目架构图，能够缩放或在页面内完整阅读。
4. 抽查表格、列表、脚注/引用、内部链接和外部链接。
5. 调整字号、浅色/深色主题和横竖屏，正文不丢失，图片替代文本可被辅助功能识别。

每台设备必须通过 `navigation`、`diagram`、`code`、`table` 四项，失败项修复后使用同类实体设备复验。

## 印刷样张

使用最终 A4 PDF 制作至少一份实体样张；推荐同时抽取 32 页骑马钉/胶装小样和关键彩色页。记录打印设备或印厂、纸张克重、装订方式和缩放设置（必须为 100%，不得“适合页面”）。检查：

- 装订内边距、页码、页眉和裁切安全区；
- 灰度下箭头、线型、节点和状态分支仍可区分；
- 6—8pt 代码、长 URL、表格边框和中文标点清晰；
- 全页图、跨页章节、目录、索引和参考资料无意外空白或孤行；
- 字体嵌入、打印机替换字体和黑块问题为 0。

只有实体样张的边距、灰度、图示和代码四项全部通过，`print_proof.result` 才能填写 `pass`。

## 记录与隐私

照片可保存在私有档案中，仓库只记录设备类别、OS/阅读器、检查结果和档案引用。照片出现通知、账号、书签或设备所有者信息时必须先脱敏。
